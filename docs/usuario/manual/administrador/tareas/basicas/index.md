# Tareas básicas

Las tareas básicas son aquellas que se derivan directamente de los controles de la API SITNA. Son las tareas que ofrecen la interacción básica con el usuario en el visor.

Las tareas básicas ya vienen integradas por defecto en la instalación base de SITMUN 3.

Para que las tareas básicas puedan visualizarse en el visor, es necesario asignar a cada tarea básica un rol y un territorio. La tarea se mostrará en el visor cuando el usuario acceda con permisos que coincidan con los roles y territorios asignados.

Desde el punto de vista del administrador, no es necesario realizar ninguna otra acción sobre estas tareas.

## Parámetros

Las tareas básicas son parametrizables.

Los parámetros que pueden añadirse a estas tareas son aquellos admitidos por los controles de la API SITNA.

En la descripción de cada tarea básica se muestran ejemplos de posibles parámetros que pueden contener estas tareas.

## Tareas básicas incluidas

Las tareas básicas que incluye SITMUN se describen agrupadas en cuatro páginas:

| Grupo | Tareas |
| --- | --- |
| [Navegación y vista](navegacion.md) | 3D View, Full screen, Geolocation, Navigation Bar, Overview Map, Scale, Scale Bar, Scale Selector, Street View |
| [Capas](capas.md) | Basemap selector, Data Loader, Layer Catalog, Legend, Work Layer Manager |
| [Información](informacion.md) | Click, Coordinates display, Feature Info, More Info Advanced, Multi Feature Info, Popup |
| [Herramientas](herramientas.md) | Attribution, Download, Draw, Measure and Modify, Loading Indicator, Measure, Offline Map Marker, Print Map, Search, Share, WFS Query, WFSEdit |
