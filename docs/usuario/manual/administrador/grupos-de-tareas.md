# Grupos de tareas

La opción **Grupo de tareas** sirve para crear categorías con las que clasificar las diferentes [tareas](tareas/index.md) que se vayan creando. La pestaña **Tareas** del grupo lista sus tareas y permite añadir o quitar tareas del grupo.

Hay que tener en cuenta que con el tiempo se pueden acumular muchas tareas diferentes, y puede facilitar su gestión tenerlas clasificadas según categorías que el administrador puede crear según sus necesidades.
