# Anexo I: variables de sistema

Con el fin de poder interactuar con la propia aplicación de SITMUN, se ofrecen algunas variables de sistema que pueden utilizarse en la aplicación de administración de SITMUN, por ejemplo en las [consultas SQL](tareas/consulta.md#parametros-en-las-consultas-sql).

Para identificar dichas variables siempre es necesario que empiecen por el símbolo `#` y estén dentro de un par de llaves `{ }`.

Las variables que proporciona actualmente SITMUN son:

- `#{LANGUAGE}`
- `#{APP_ID}`
- `#{MUN_INE}`
- `#{TERR_COD}`
- `#{TERR_NAME}`
- `#{APP_NAME}`
- `#{USER_ID}`
- `#{EXTENSION_MAX_Y0}`
- `#{USER_NAME}`
- `#{EXTENSION_MAX_X0}`
- `#{EXTENSION_MAX_Y1}`
- `#{EXTENSION_MAX_X1}`
- `#{LANG}`
- `#{USUARIO}`
- `#{MUN_INES}`
- `#{DATE}`
- `#{APP_CODIGO}`
- `#{USU_CODIGO}`
- `#{PROYECCION}`
- `#{TERR_ID}`
- `#{TER_CODIGO}`
